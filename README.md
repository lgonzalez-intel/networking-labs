# Networking & Cybersecurity Labs

Hands-on labs I build while studying ASIR (IT systems & networks) and working towards a blue team / SOC role.
Each project has its own folder with the files needed to reproduce it and a README explaining the setup, the tests and what I would change in a real environment.

## 📂 Projects

| # | Project | Tools | Topics |
|---|---|---|---|
| 01 | [Multi-site network with DNS and web services](01-multisite-dns-network/) | Cisco Packet Tracer | Static routing · Serial WAN links · DNS · DHCP · Addressing design review |
| 02 | [Two-site network with WPA2-Enterprise Wi-Fi and SSH](02-wpa2-enterprise-radius-ssh/) | Cisco Packet Tracer | WPA2-Enterprise · RADIUS (AAA) · DHCP server · SSH vs Telnet · Static routing |

## 🧭 How each project is documented

- **Objective** — what the lab sets out to do
- **Setup** — devices, addressing and configuration
- **Testing** — commands and screenshots that prove it works
- **Design review** — weaknesses found and how I would fix them
- **What I learned**
